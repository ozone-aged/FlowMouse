# v2.5-ozone.1 · 2026-10-21

Hmily-LCG/FlowMouse **v2.5** 소스 ZIP을 독립 복사한 첫 개선판입니다. Chrome/Edge 확장 버전은 **2.5.0.1**입니다. 원본 작성자·GPL-3.0·타사 라이선스와 원본 버전 태그를 보존했습니다.

- 설정 찾기: 검색어로 설정 영역을 찾고 바로 이동합니다. Ctrl+K / ⌘K, Enter, Escape와 한국어를 지원합니다.
- 접근성: 포커스 표시, 팝업 컨트롤 이름, 저장 상태 알림과 동작 줄이기 설정을 보강했습니다.
- 가져오기 보호: 1 MiB 제한, 컨테이너·기본 자료형·동작 구조 검사, 위험한 프로토타입 키·과도한 중첩 차단을 추가했습니다. v2.5와 기존 제스처 맵 마이그레이션은 유지합니다. 알 수 없는 미래 설정은 덮어쓰기 전에 거부합니다.
- 가져오기·내보내기·초기화 전에 대기 중인 편집 저장을 완료해, 이전 값이 새 설정을 뒤늦게 덮어쓰는 문제를 막았습니다.
- 좁은 창에서 헤더·버튼·제목이 넘치지 않도록 배치를 보완했습니다.
- 저장 안정성: 연속 쓰기를 순서대로 처리하고 저장에 성공한 상태만 반영합니다. 저장/초기화가 실패하면 기존 설정을 유지하고 오류를 표시합니다.
- 기본 제스처·드래그·명령 체인·권한은 원본 그대로 유지합니다. 권한·호스트 접근 범위를 추가하지 않았습니다.

## 설치

`FlowMouse-Chromium-2.5.0.1.zip`을 받고 압축을 푼 뒤 Chrome/Edge의 확장 관리 화면에서 개발자 모드 → 압축해제된 확장 프로그램 로드로 설치합니다. [Windows/macOS 설치·업데이트 안내](INSTALL.ko.md)를 참고하세요. 스토어 자동 업데이트가 아닌 수동 ZIP 교체 방식입니다.

원본 확장과 개선판을 동시에 켜면 동작이 겹칠 수 있으므로 원본 설정을 내보내 이 개선판에 가져온 후 원본을 꺼 둡니다. Firefox 설치판은 포함하지 않습니다.

## 검증

TypeScript 검사, 자동 검사 7개, 임시 Chromium의 실제 확장 UI·기본 뒤로가기 제스처·설정 가져오기 검사를 통과했습니다. 의존성 감사 결과 알려진 취약점 0건입니다. 최종 설치 ZIP을 풀어 다시 검증했습니다. macOS arm64 Chromium에서 실행했으며 Windows/Edge 실기 검증은 수행하지 않았습니다. 상세 범위는 [보안·호환성 검토](SECURITY-REVIEW.md)에 기록했습니다.
